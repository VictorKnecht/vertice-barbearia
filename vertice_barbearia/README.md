# Vértice Barbearia — projeto demonstrativo ALVORA

Site fictício criado para o portfólio da ALVORA Tecnologia.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro

## Como visualizar
Abra o arquivo `index.html` no navegador. Não precisa instalar Node.js nem executar build.

## Antes de apresentar como site de cliente
- Substitua o número fictício `5546999999999` em `js/script.js`.
- Atualize nome, endereço, horários, serviços e preços.
- Troque as imagens de demonstração por fotos autorizadas do estabelecimento.
- Os preços, equipe e informações apresentados são ilustrativos.
- As imagens são carregadas de URLs do Unsplash e precisam de internet.

## Publicação
Para hospedagem estática, envie a pasta do projeto para o repositório e configure a hospedagem para servir a raiz do projeto.
